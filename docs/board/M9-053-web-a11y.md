## Problem

Icon-only controls had no accessible names, the transcript had no log role, and
the theme default ignored the OS color-scheme/contrast preference.

## Scope

- Add a skip-to-transcript link.
- Label context/sidebar/theme/download/search/filter/prompt controls.
- Mark the transcript `role="log"` with polite live updates; live/busy chips are
  polite live regions.
- First-run theme: saved value wins; else `prefers-contrast: more` → high
  contrast, else `prefers-color-scheme: light` → light, else dark.
- Auto selection is not persisted until the user toggles.
- No server/session changes.

## Acceptance

- [x] Icon buttons have `aria-label`.
- [x] Transcript has `role="log"` and an accessible name.
- [x] Search/filter/prompt inputs are labeled.
- [x] OS contrast/light preference influences the first theme.
- [x] Explicit toggles persist; auto selection does not.
- [x] Static assertions cover log role and contrast preference.

## Notes

Streaming updates on a polite live region can still be chatty; a "announce final
only" mode is a possible follow-up.
