## 范围

- `niucode` 无参数时打印版本、状态、会话目录和下一步。
- `niucode session new` 创建会话并写入 `session_start`。
- `niucode session show` 打印事件时间线，`niucode session list` 列出文件。

## 验收

- [x] `niucode session new` 输出可直接被脚本消费的路径。
- [x] `niucode session show <path>` 显示事件数与 warning。
- [x] 默认目录支持 `NIUCODE_HOME` / `HOME` 覆盖。

## 记录

`exec` 子命令等 loop 落地后再加，避免先有一个假入口。
