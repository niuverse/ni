## 范围与验收

首轮每题每配置只运行一次，用于建立可审计基线。稳定胜负、增强轨收益与泛化能力
需要后续重复和更有区分度的任务，不应由简单题的一次成功率推出。

- [ ] 在追加调用前冻结新的 campaign、重复次数、版本、费用上限和选择规则。
- [ ] 每配置至少 3 次配对重复，公开全部尝试；同题重复不当成独立新任务。
- [ ] 根据首轮错误或天花板效应增加跨文件变更、约束组合和依赖故障任务。
- [ ] 新题同样要求原始回归通过、新验收失败、参考修复通过、错误修复被拒绝。
- [ ] 新版本与 v1 分开报告，发布逐题配对与不确定性；不只保留最佳结果。

首轮自建题 niucode 基础/增强均 8/8，费用上界约 ¥0.97/¥1.83。
后续预注册更简洁验证流程的对照，观察验证命令是否重复、是否保留必要边界检查。
目前只有单次运行，不能据此认定增强流程无效，也不能把费用上界当作实际账单。
