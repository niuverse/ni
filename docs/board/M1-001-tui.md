## 范围

- 流式渲染文本、reasoning 折叠、工具调用状态。
- 审批提示：单键 allow / deny / allow-for-session。
- diff 预览，先看再批。
- Ctrl-C 取消当前 turn，二次强制退出。

## 验收

- 首 token 到达即渲染，不等完整响应。
- 审批时终端不丢输入、不卡死。
- 取消后进程组被清理，session 留下明确事件。
- 窄终端（80 列）仍可读。

## 记录

TUI 只消费事件流，不 import loop 内部。先做线性输出，再做花活。
