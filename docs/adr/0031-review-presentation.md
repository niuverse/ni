## 状态

Accepted · 2026-10-21 · 用户授权实施 M6-011 至 M6-015，并优化高亮与运行反馈。

## 决策

- agent 审阅投影返回结构化变化、覆盖缺口、检查与任务状态；未知 digest 不是变化证据。
- CLI 负责文案和显示预算，任务结束仅一个呈现责任点；完整证据进入详情。
- 快照仍在任务开始和结束采集。相同 digest 的 UTF-8 正文只需在同一日志记录一次；后续 `text: null` 可从此前快照中匹配并校验 digest 的正文恢复。没有对应正文时明确无法恢复 diff，不读取当前磁盘充当历史内容。
- 取消后的收尾快照最多等待 100ms，超时明确记录覆盖未知；此前已记录的工具证据保留。正常任务仍使用既有扫描预算。
- 不新增 core 字段，不改旧日志。投影只能使用目标事件之前的内容；fork 的前缀包含其引用内容，坏尾行不导致自动重放。
- 哈希读取预算与正文保存预算分开：读取仍受文件/字节/时间限制；保存只包含日志尚未记录的正文。覆盖未知显式保留。
- 临时 digest 集合可由日志重建，不是第二份持久状态。缓存有界，超出只降低去重率，不丢失证据。
- 高亮在清洗和布局后由终端所有者生成，不接受模型 ANSI。状态动画仅刷新活动区，禁色/非 TTY 时保持静态，不改变 scrollback 或审批语义。

## 后果

旧版读者仍能读取事件，但可能把复用正文的历史 diff 显示为 unavailable；新版投影恢复完整已记录正文。
首次采集仍有成本；此方案降低正文重复写入，不声称无需扫描或覆盖整个仓库。
真实 Linux/macOS、复制、IME 与 Ghostty gate 仍需实机证据，自动化验收不替代。
