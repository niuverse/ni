## 状态

Accepted · 2026-10-21 · 用户已确认产品契约；实现计划见 `docs/pairing-upgrade.md`。Accepted 表示决策被接受，不表示 M6 已实现或跨终端验证通过。

## 背景

niucode 的目标是日常结对编码。当前两套 editor 的输入行为不一致；TUI 执行期间没有输入通道；read-before-write 只检查读过的路径；工具调用成功不等于命令退出成功。用户要求系统性升级，并明确要求 robust、clean，不接受 dirty hack。

## 决策

1. **终端原生交互。** 主 transcript 使用原生 scrollback，保留选择复制与终端搜索；活动输入区统一管理。临时详情与审批可以使用 alternate screen，不引入常驻全屏应用。
2. **单一编辑与终端所有者。** 编辑状态、Unicode 布局与补全共享；终端能力适配只负责实际差异。所有交互输出和终端事件读取集中管理，禁止后台直接打印和品牌分叉的编辑器。
3. **落实 ADR-0004 的 Command/Event 边界。** runtime 位于 agent，拥有唯一会话日志 writer；TUI/CLI 发送命令、消费事件。UI 不调用 loop 内部，不维护第二份可持久会话状态。
4. **运行中 Enter 补充当前任务。** 补充先落日志，再在安全的下一请求边界注入；待接收/已接收有明确语义。排队任务使用显式动作，取消保留已完成事实和当前草稿。
5. **Reasoning 默认收起。** 主屏显示状态、耗时与实际进展；已记录 reasoning 通过详情访问。M6-006 已切换默认行为，替代 ADR-0021 的第 3–5 条默认展示策略。中断流未完整落盘时不得声称可恢复全部 reasoning。
6. **共享工作区是默认方式。** 对文件工具实现内容版本与预览失效检测；外部编辑和任意 shell 写入不受内部写锁完全约束。采用乐观检测，明确残余竞争窗口；未知来源不自动归因，不自动回滚用户变化。
7. **审阅来自实际证据。** 即时简报加本轮累计 diff，以任务开始工作区为基线；保持原有未提交内容和 index。结构化记录检查退出状态，区分成功、失败、取消、未知/未验证；后续修改使先前验证可能过期。
8. **持久事实仍在日志。** 接收/排队/任务边界、受预算约束的审阅事实属于事件；缓存可删除，超预算的内容明确不可完整重建。布局、刷新、未提交草稿是临时状态。core 仅增加必要的持久类型。
9. **Linux/macOS 都是验收平台。** Ghostty、Kitty、WezTerm、代表性系统终端及其 tmux 组合记录具体版本和测试证据。TUI 支持不等于跨平台沙箱已实现，禁止为了通过 UI 测试静默放宽权限。
10. **渐进迁移。** 每阶段保持可用、可回归；旧实现有删除门槛。既有 Ghostty fallback 遵循 ADR-0022，在真实回归通过前不移除；不得用新增特判长期掩盖架构缺陷。

## 后果

- 运行中输入需要重整执行/审批生命周期，不能仅更换 widget。
- 新增持久事件需覆盖旧日志、projection、resume、fork 与 JSON 兼容；不重新解释已有 TurnEnd/ToolResult.ok。
- 共享工作区保留即时反馈，但不提供对任意外部程序的事务隔离或 exactly-once 执行保证。
- 实机矩阵是发布门槛；自动化测试通过不能代替真实终端证据。
- 不新增通用框架、daemon、前端插件系统或 Windows 本轮支持；真实编码任务评测另立后续里程碑。

## 关联

## 实现记录 · 2026-10-21

- Composer/Completion 只管输入状态；TerminalSession/DetailScreen 管模式与呈现，live 是活动 TUI 的唯一事件循环。删除独立 inline editor。
- crossterm 统一到 0.29，避免两版本各持有输入/模式状态；使用 level-triggered `use-dev-tty` 输入后端与正超时有界轮询。PTY 覆盖 resize 与按键同时到达，无终端品牌特判。
- SessionLog 保留一个 writer，内部 Mutex 串行化完整 append；首个 I/O 失败后禁用 writer，不重试可能部分写入的事件。新增输入、任务与证据事件，core 不依赖任何 UI/执行组件。
- prepare/preview/apply 使用同一不可变修改对象，W1 在审批后获取；命令证据快照在释放 W1 前采集。外部编辑的最终校验/替换竞态仍存在。
- 回调式 headless 与通道式 TUI 复用同一引擎；旧 JSON / resume / compaction / subagent fixture 保持回归。真实终端矩阵、慢输出压力和跨平台结果单独记录，未宣称已通过。

### 交互补充 · 2026-10-21

用户要求模型/权限选择一次确认生效。TTY 的 `/model` / `/permissions` 进入参数菜单，打开不改配置，Enter 或点击选择后直接沿现有命令路径执行，Esc 取消，Tab 仅补全。此处更新 ADR-0015 的 TTY 裸命令展示行为；非 TTY 查询与事件/权限边界不变。输入/菜单焦点通过标准光标形状和可见性表示，退出恢复终端默认形状，不增加终端品牌判断。

### 文本布局收敛 · 2026-10-21

用户选择统一文本布局并继续删除重复实现。CLI 内的 `text_layout` 负责字素宽度、
换行、控制字符可视化、tab 和裁剪；Composer 保留编辑/历史状态，TerminalSession
保留终端所有权。输入与输出复用布局算法，只有输入生成位置映射并预留满行后的光标格。
静态输出不创建 Composer，不生成 undo/history，也不保存另一份会话状态。

输入、流式预览、inline transcript、详情和 diff 共享字素规则；linear transcript
继续交给终端原生软换行。tab 使用逻辑行上的四列制表位，不因软换行改变列宽。
输出换行函数按逻辑行限制 1 MiB 源文本，在字素边界保留前缀并显示
`[display truncated]`，不丢弃后续诊断行。显示标记不代表原始日志被截断，亦不承诺
未落盘内容可恢复。diff 继续拥有行号和 gutter，不引入通用 renderer 框架。
